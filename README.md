# ClassPulse – Smart Attendance Tracker

A responsive web-based attendance tracking dashboard built with **HTML**, **CSS**, and **JavaScript** to help students monitor overall and subject-wise class attendance.

## Features

- **Student Login Portal**: Clean demo login interface (`index.html`) with form validation.
- **Overall Attendance Calculator**: Tracks total classes, classes attended, missed classes, and target percentage.
- **Subject-Wise Tracking**: Displays live attendance percentages, dynamic progress bars, and status indicators across subjects.
- **Responsive Design**: Clean, mobile-friendly layout styled in `style.css`.
